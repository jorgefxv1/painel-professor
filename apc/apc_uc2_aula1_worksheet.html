O Ecossistema por Trás do Big Data

APC — Atividade Prática de Classe · UC II (Ecossistema de Big Data II) · Aula 01
Nome:
Turma:

Como o YouTube consegue sugerir o vídeo certo entre milhares publicados a cada minuto, no mundo inteiro? Nenhum sistema sozinho dá conta disso — é um conjunto de tecnologias trabalhando juntas, cada uma cuidando de uma parte do processo. A esse conjunto damos o nome de ecossistema de Big Data.

Um ecossistema é um conjunto de elementos diferentes que interagem entre si pra manter um sistema funcionando — igual numa floresta, onde árvores, animais e solo dependem uns dos outros. Big Data é o nome dado a conjuntos de dados grandes e complexos demais pra serem tratados por ferramentas comuns. O Ecossistema de Big Data, então, é todo o conjunto de tecnologias (bancos de dados, nuvem, sistemas de processamento) que trabalha junto pra coletar, guardar e processar esse volume de dado — como uma biblioteca gigante, com um sistema de catalogação, prateleiras e bibliotecários trabalhando em conjunto.

Esse ecossistema costuma ser descrito pelos 3 Vs do Big Data:
Volume
quantidade de dado gerado (ex.: bilhões de registros)
Velocidade
rapidez com que o dado chega e precisa ser tratado
Variedade
diferentes tipos e formatos de dado (texto, imagem, áudio, vídeo)
