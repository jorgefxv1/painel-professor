Revisão dirigida · UC I (Ingestão de Dados) · 4º Bimestre
Nome: Turma:

Esta folha revisa, com mais pistas, os mesmos quatro temas da prova: raspagem da web, limites da coleta, APIs e viés na coleta de dados. Leia a dica antes de responder cada questão.

1Raspagem de dados
Dica: raspagem é SEMPRE automática — se alguém está digitando na mão, não é raspagem.
Marque a alternativa correta.
A Copiar o texto de uma página e colar manualmente em uma planilha, célula por célula. B Usar uma função (como IMPORTHTML) ou programa para extrair automaticamente um dado publicado em uma página e organizá-lo. C Excluir dados duplicados de uma planilha.
2O que o robots.txt faz?
Dica: pense nele como uma placa de "não entre aqui" que o próprio site coloca para robôs.
Complete: o arquivo robots.txt de um site serve para avisar quais partes do site _______________ ser visitadas por robôs automáticos de coleta.
3Dado público é dado livre?
Dica: "estar visível" e "poder usar sem restrição" não são a mesma coisa.
Se um dado está visível numa rede social, qualquer pessoa pode coletá-lo automaticamente e usar como quiser, sem nenhuma restrição.
Os termos de uso de um site podem proibir a coleta automatizada mesmo de conteúdo que qualquer visitante consegue ver.

5Por que usar API em vez de raspar a tela?
Dica: pense em estabilidade — uma tela muda de aparência com frequência; um dado de API é mais previsível.
Complete com UMA vantagem da API sobre a raspagem de tela: a API entrega o dado já _______________ , diferente de uma página pensada para leitura humana.
6Lendo um JSON simples
Dica: cada linha do JSON é um par "nome do campo": valor.
No JSON {"cidade": "Corumbá", "temperatura_celsius": 30}, qual é o valor do campo "cidade"?

7Encontrando o viés — passo a passo
Dica: pergunte sempre "quem tinha chance de responder, e quem não tinha?"
Uma farmácia fictícia coloca uma caixinha de papel no balcão com a pergunta "Você recomendaria nossa farmácia?" — só quem compra e passa pelo caixa vê a caixinha.
a) Quem nunca teria a chance de responder essa pesquisa (mesmo sendo cliente da região)?
b) Entre quem passou pelo caixa, quem está mais motivado a parar e responder — quem ficou satisfeito ou quem ficou insatisfeito?
8Revisão final — verdadeiro ou falso
Uma base de dados pode estar sem nenhum campo vazio e, ainda assim, ter um problema grave de viés de amostragem.
O rate limit de uma API existe para impedir que um usuário sobrecarregue o sistema com requisições em excesso.
