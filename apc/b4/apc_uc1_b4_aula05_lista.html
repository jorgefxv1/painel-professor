APIs: a Porta Oficial de Ingestão

APC — Atividade Prática de Classe · UC I (Ingestão de Dados) · Aula 05
Nome: Turma:

Um app de previsão do tempo não "adivinha" a temperatura de uma cidade: ele pede esse dado a um sistema que já tem a informação organizada. Esse pedido tem endereço, regras e uma resposta num formato que a máquina entende de cara. Essa porta oficial de pedir dado a outro sistema se chama API, e ela resolve boa parte dos problemas que a raspagem (Aula 01) deixa em aberto.

API (Application Programming Interface) — interface pela qual um sistema oferece seus dados e serviços a outros, de forma organizada.
Uma requisição tem três partes: endpoint (o endereço, ex.: /clima), parâmetros (o que você está pedindo, ex.: ?cidade=Corumba) e a resposta (quase sempre em JSON — pares campo-valor e listas entre colchetes).

API key — uma chave de acesso que identifica quem está pedindo o dado.
Rate limit — o limite de quantas vezes você pode pedir dado num período, antes da API recusar.

Por que API é melhor que raspagem, quando as duas existem: o dado já vem estruturado (sem precisar entender o HTML da página), estável (a API tem contrato, a página pode mudar de layout) e autorizado (quem publica a API quer que você use o dado daquele jeito).
