2Robots.txt e termos de uso 1,0 pt
Classifique cada afirmação como Verdadeira (V) ou Falsa (F). Cada item vale 0,25 pt.
O arquivo robots.txt de um site informa quais partes do site não devem ser raspadas por robôs automáticos.
Se um dado está publicado e visível na internet, a pessoa pode fazer qualquer uso dele, sem restrição.
Os termos de uso de uma rede social podem proibir a coleta automatizada de dados do site, mesmo que o conteúdo seja público.
A LGPD (Lei Geral de Proteção de Dados) só se aplica a empresas, nunca a dados coletados para fins de pesquisa.

7API x raspagem 1,0 pt
Classifique cada afirmação como Verdadeira (V) ou Falsa (F). Cada item vale 0,25 pt.
Um dado vindo de uma API costuma chegar mais estruturado e estável do que um dado raspado de uma página pensada para leitura humana.
Uma API nunca exige autenticação, diferente da raspagem, que sempre exige.
O "rate limit" de uma API existe para impedir que um mesmo usuário sobrecarregue o sistema com excesso de requisições.
Se uma página muda de layout, uma raspagem feita com IMPORTHTML pode parar de funcionar; uma API bem documentada tende a ser mais estável a esse tipo de mudança.

b) Se você quisesse a previsão de outra cidade, o que precisaria mudar na requisição feita a essa API?
