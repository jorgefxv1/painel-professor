ETL x ELT: a cozinha explica tudo

Turma: 2º Ano A/B — IntegralProf.: Jorge FriasData: ___ / 09 / 2026

Dado chega bagunçado, como ingrediente cru. Uma hora alguém precisa arrumar. ETL arruma antes de guardar. ELT guarda primeiro e arruma depois. Só isso muda.

As três letras

E Extract · extrair

Pegar os ingredientes na geladeira.

Dados: buscar na fonte — planilha, banco, app, sensor.

T Transform · transformar

Lavar, cortar, temperar, jogar fora o que estragou.

Dados: corrigir erro, padronizar data, tirar duplicado.

L Load · carregar

Servir o prato na mesa.

Dados: guardar no destino final, pronto para usar.

Lote x tempo real — o ritmo em que o dado entra

ETL/ELT é a ordem. Lote/tempo real é o ritmo. Pergunta diferente.

Lote — lavar roupa

Você junta a roupa da semana e lava tudo de uma vez. Os dados acumulam e são processados juntos, num horário marcado.

Ex.: banco fecha as contas do dia à meia-noite. Backup do celular de madrugada.

Tempo real — beber água

Você bebe na hora em que sente sede. Cada dado é tratado assim que chega, sem esperar juntar.

Ex.: cartão bloqueado na hora da compra suspeita. Trânsito no GPS.

Pergunta para decidir: alguém está esperando a resposta agora? Sim → tempo real. Não → lote (mais barato).

Roteiro para o quadro

  • DesenheGeladeira → Cozinha → Mesa. Escreva E, T, L embaixo de cada um. Pergunte: "o que acontece em cada lugar?"
  • Fale"Isso é ETL. O chef arruma antes de servir. O prato chega pronto e confiável."
  • DesenheAo lado: Geladeira → Mesa → pratinho de cada um. Troque a ordem das letras: E, L, T.
  • Fale"Isso é ELT. Self-service. Tudo vai cru pra mesa, cada um arruma quando for comer. Mais rápido pra encher a mesa, mas guarda até o que ninguém vai usar."
  • Pergunte"Boletim da escola: pode chegar com nota errada?" (não → ETL). "Instagram guardando todo clique: dá pra arrumar cada um antes?" (não → ELT).
  • Feche"Lote é lavar roupa junto. Tempo real é beber água na hora. Isso é o ritmo — não confundir com a ordem."

Três perguntas rápidas

  1. Qual é a única diferença entre ETL e ELT? Explique com a cozinha.
  2. Trocar a data "14/09/2026" por "2026-09-14" é E, T ou L? Por quê?
  3. Diga se é lote ou tempo real: a) relatório de vendas do mês; b) alerta de batimento cardíaco; c) folha de pagamento; d) recomendação de vídeo enquanto você assiste.
